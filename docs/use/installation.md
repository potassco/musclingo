# Installation

The *musclingo* system is available in [PyPI](https://pypi.org/project/musclingo/).
Install it using pip by running the following command in your terminal:

```console
pip install musclingo
```

-----

A successful installation will make the `musclingo` command available in your terminal. You can check the installation by running:

```console
musclingo -h
```

This will display the help message with available options and usage instructions, for detailed CLI information refer to the [CLI documentation](../reference/cli/index.md).
